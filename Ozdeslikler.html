📋 Özdeşlik Şablonları

1. İki Kare Farkı x² − y² = (x − y)(x + y)
2. Tam Kare Açılımı (x ± y)² = x² ± 2xy + y²
3. İki Küp Farkı / Toplamı x³ ± y³ = (x ± y)(x² ∓ xy + y²)
4. Parantez Küpü (x ± y)³ = x³ ± 3x²y + 3xy² ± y³
5. Dördüncü Derece Fark x⁴ − y⁴ = (x − y)(x³ + x²y + xy² + y³)
6. Beşinci Derece Fark x⁵ − y⁵ = (x − y)(x⁴ + … + y⁴)
7. Altıncı Derece Fark x⁶ − y⁶ = (x − y)(x⁵ + … + y⁵)

Özdeşlikler

Şablonları kullanarak açın veya çarpanlara ayırın.
Süre sınırı yoktur. 14 soru vardır (her şablon +/−).

Örnekler:
(x + 3)² → x² + 6x + 9
x² − 25 → (x − 5)(x + 5)
(2x − 1)³ → 8x³ − 12x² + 6x − 1
